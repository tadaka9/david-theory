# GitHub publication status

The validation program was published in `tadaka9/david-theory` through pull request #1 and merged into `main` at commit `e8dc788293ba0e5b3847e2e4ae6e74a5f539d8a2`.

The published material includes the paper, executable analyses, synthetic controls, saved results, empirical audits, mathematical status, laboratory protocol, prospective preregistration, tests, and Linux/Windows GitHub Actions.

The synthetic files are software controls and must not be described as disciplinary observations. The psychology analysis tests an external predictive extension rather than the definitional identity. The economics analysis is an accounting consistency audit rather than independent confirmation.

Future changes should use a branch and pull request, run the commands in `README.md`, report every result, and preserve the original deposited PDFs.
