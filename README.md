## Reproducible validation program

The [`validation/`](./validation/) directory separates the algebraic identity
`H := E - h` from empirical extensions that can fail. It contains synthetic
controls, real-data exploratory analyses in occupational psychology, a World Bank
accounting audit, mathematical status, prospective preregistration, laboratory
protocols, automated tests, and Linux/Windows GitHub Actions.

Current evidence does not establish a universal law. The fixed-weight psychology
extension is rejected in the formal sample and receives a partial internal
replication in the pilot sample. The economic analysis is a consistency audit, not
independent confirmation, because gross savings is defined from national-accounts
components including net transfers. See [`validation/PAPER.md`](./validation/PAPER.md)
for results and limitations.
